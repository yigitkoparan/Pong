# 🏓 Classic Pong (Unity 2D)

A responsive, polished recreation of the classic arcade game *Pong*, built using **Unity** and the **New Input System**. It features smooth physics-based movement, an interactive AI opponent, a custom vector-bounce mechanic, and responsive UI menus.

---

## ✨ Features
* **New Input System Implementation:** Modern, event-driven player input for fluid paddle movement.
* **Smart AI Opponent:** Dynamically tracks the ball only when it crosses onto the AI's side of the court.
* **Arcade Vector Bounce:** The ball changes its reflection angle depending entirely on where it strikes the paddle (top, center, or bottom).
* **Fully Dynamic UI:** Scalable, responsive Main Menu and a real-time Pause Menu (`Esc` key) designed with custom TextMeshPro layouts.

## 🛠️ Built With
* **Engine:** Unity 2D
* **Language:** C#
* **Version Control:** Git & GitHub Desktop
* **UI Framework:** TextMeshPro (TMP)

## 🎮 How To Play
* **Move Up/Down:** `W` / `S` or Arrow Keys
* **Pause Game:** `Escape`
